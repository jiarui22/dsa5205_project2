# 回测与 Barra 收盘价迁移

## 当前实现

主链路已改为 `close_adj`：`workflow.backtest/evaluate`、分层回测、回测报告、Barra 模型日收益及归因适配均不再要求 VWAP。原始 VWAP 数据和原公式的含义保留，不批量改名或伪造。

统一时点：**T 收盘后信号 → T+1 收盘近似成交并记费用 → T+2 首笔持仓收盘收益**。这是对先前“次日开盘执行”方案的明确修订；只有 close 不能声称模拟了 open。

| 对象 | 新口径 |
|---|---|
| 主 ylabel | `close_adj[T+10]/close_adj[T]-1`，未中性化、未标准化 |
| 日收益 | `close_adj[d]/close_adj[d-1]-1`，拒绝未知复权分段 |
| 回测 weights[d] | d 日收益区间开始时的实际权重，不是 d 日新信号权重 |
| post_close_weights[d] | d 收盘调仓及费用后权重 |
| 手续费 | 真实调仓日成交金额乘费率；初始建仓与默认期末清仓计费 |
| 漂移与低频调仓 | 非调仓日持仓按收益漂移，不重复收费；支持 rebalance_every |
| Barra 回归 | 用 d-1 收盘可知暴露解释 d 日收盘到收盘收益 |
| SPY 绩效基准 | 独立 `indices_total_return_close`，首次执行收盘开始持有，基准费用假设为 0 |
| 风格主动参考 | 同池前收盘市值加权成分参考，**不冒充 SPY 成分持仓归因** |

费用计算使用费用后 NAV 的目标权重并解自融资费用关系；不把买入金额与账户 NAV 混为同一分母。复权收盘仅是收益与权重研究代理，不是历史真实成交报价、完整现金分红账本或精确收盘集合竞价撮合。

股票选择只用信号日资格与信号值。不因下一日缺报价、不可交易或后来退市，重新选择第二名。交易失败、持仓收益缺失和未知收益链接显式报错，不填零。

Barra 缓存签名已换成收盘收益和前收盘暴露，旧 VWAP 模型不能静默复用；请选择新的 model_dir 重建。未使用的 VWAP/amount/未来标签文件不影响新风险缓存。财务现金流字段统一识别 `operating_cash_flow_ttm`，兼容旧拼写但冲突时报错；换手率优先配对 CRSP 成交量与 CRSP 股数，而不是替换成收盘收益。

标签结束日期的读取也已统一为明确字符串、完整日历检查。因子筛选和训练不能再因 CSV 索引被推断成整数而出现空的开发样本；旧筛选日志不能直接混用新的日期规则。

## 不适合机械替换的地方

1. **原始因子公式中的 VWAP**：换成 close 就是另一个因子，必须独立命名与验证。原始真实成交金额、成交量、滑点和交易容量也不能由 close 代替。
2. **开盘执行假设**：如以后恢复 T+1 开盘成交，必须使用 open_adj 并分别计算隔夜与日内收益，不能把 close 参数换个名字。
3. **退市、并购现金／换股结算**：终止事件可能没有收盘价。需核实原始终止收益、有效日期、现金或换股结算及持仓转换，不能沿用旧价、填 0 或事后删掉股票。
4. **SPY 风格主动归因**：只有 SPY 价格不足以还原其成分股风险暴露。当前报告的 SPY 超额收益与同池参考的风格归因分别标注。
5. **不完整风险描述子**：换成 close 不会补齐 Growth、优先股等资料，不得宣称完整商业 Barra。

真实数据已验证一个明确例外：`CNA:039203:01 / IMGO` 在源数据 2023-01-11 上 `delisting_event=1`、`trade_available=0`、`close_adj=NaN`，而供应商 `daily_return` 仍有约 -0.000278 的终止收益记录。历史证券有效期结束于 2023-01-10。源数据证据足以说明不能靠收盘字段覆盖这一天；它**不等于**已经核实了完整现金／换股结算账本。全池分层因此正确阻断，不事后删除 IMGO 规避。同池市值参考主动归因另在 2023-01-04 首先遇到持仓行业缺失，不能把这一检查失败误记为已通过或同一退市原因。

## 验证与边界

- 两个隔离环境的回归测试覆盖初始成本、期末退出、信号延迟、持仓漂移、未知分段、无未来报价重选、SPY 独立列轴、费用与归因恒等式。
- 集成测试在完全没有 VWAP、以及 VWAP/amount 全为 NaN 两种情况下，常规回测和 Barra 输出一致；不使用 VWAP 的风险缓存可复用。
- 短期真实数据检查使用固定 SID 排序，不是因子策略，不训练 Ridge/Lasso/XGBoost。常规组合绝对归因与全池终止事件检查分开报告，不把前者通过称为整库通过。
- 原始下载文件和既有数据快照不修改。旧标签快照中的“当时尚未迁移”说明属于历史构建状态，当前代码状态以本文和迁移验证报告为准。

```sh
PYTHONPATH=src python -m pytest tests -o addopts='' -q
```

真实数据读取环境可用 `requirements-close-tests.txt` 重建；它是接口测试依赖，不是已完成的模型训练环境。正式研究仍需解决已知终止事件、股票池生成规则及每日 4,000+ 范围等独立问题。
